Imagine un petit colis 📦

📦 Le colis

C'est un message qu'on veut envoyer.

🛤️ Le chemin

C'est le réseau. Parfois, le chemin abîme ou perd le colis.

🛡️ L'arène

Elle essaie différentes façons de protéger le message pendant son voyage.

🏁 À l'arrivée

Le colis peut arriver intact, arriver abîmé ou se perdre en chemin.

Tout cela se passe dans une simulation sur l'ordinateur. Les colis et le chemin sont des images pour comprendre les messages et le réseau.

Que voit-on dans les boîtes ?

Une boîte contient un message. Choisis une phrase courte, une couleur, un petit code ou un mélange. Observe ce qui part et ce qui peut être lu à l'arrivée.

💬 Une phrase

Par exemple : « J'ai mangé une pomme. »

🎨 Une couleur

Un nom de couleur voyage sous forme de message.

🔢 Un code

Une petite suite de caractères prend place dans la boîte.

📬 À l'arrivée

Le contenu peut être intact, changé, illisible ou perdu. Seul le résultat du vrai essai est montré.

Les réglages, en mots simples

📦 Population

Le nombre de modèles de boîte (protocoles) essayés à chaque tour. Un modèle peut envoyer plusieurs messages.

🌱 Générations

Le nombre de tours. Les modèles retenus peuvent donner naissance à de nouveaux modèles au tour suivant.

🎲 Graine

Un numéro pour refaire les mêmes tirages au hasard. Garde le même numéro et les mêmes réglages pour refaire la même expérience.

📊 Le graphique

Il aide à suivre les résultats des essais au fil des tours. Un colis arrivé peut contenir un message abîmé.

Les petites boîtes et les descendants sont des images pour comprendre l'évolution : les boîtes ne sont pas réellement imbriquées dans le modèle.

Une arène pour explorer l'évolution

Règle ta population et ton environnement, puis suis les générations dans une application en français ou en anglais. Les personnages représentent les mécanismes du réseau; les animations montrent un échantillon de transmissions réellement enregistrées par le moteur.

Observer

Démarre, mets en pause ou avance une génération à la fois. Les couleurs indiquent si le message est intact, altéré ou perdu.

Comprendre

Explore les mesures, le journal et l'arbre cliquable d'un protocole. Les exemples avant/après viennent des traces enregistrées.

Conserver

Exporte une expérience en JSON ou CSV et rouvre un replay JSON.

Garder le contexte

Les résultats décrivent une simulation, pas un réseau physique. Une livraison ne garantit pas que le contenu est intact.

Démarrer sur Windows 10 ou 11

L'arène est une application Python locale. Cette page présente le projet : elle n'exécute pas la simulation dans le navigateur.

Paquet v4 pour Windows 10/11 64 bits : télécharge le ZIP, extrais-le complètement, ouvre le dossier RawHostileSelect, puis double-clique sur LANCER LE PROGRAMME.bat.

Installation à partir du code source

  1. Sur GitHub, télécharge le code avec Code → Download ZIP et extrais le dossier.
  2. Installe Python 3 avec Tcl/Tk et pip si nécessaire. Dans un terminal ouvert dans le dossier extrait, exécute :
py -3 -m pip install -r requirements.txt --target .deps
  1. Double-clique sur Démarrer_RawHostileSelect.bat.

Le téléchargement du code source et le paquet Windows sont distincts. Le guide complet bilingue détaille l'installation, les mesures et les limites du prototype.

Découvrir la v2 et l'historique du projet
On ne conçoit plus. On laisse évoluer.
Ce qui survit n’a plus besoin de ressembler à TCP, aux fichiers ou aux pages.

Des populations de protocoles (représentés comme des arbres d’opérations) s’affrontent sous bruit de bits, pertes de paquets, latence variable, pannes et attaques adversariales. La sélection naturelle décide. L’objectif est de faire émerger des abstractions radicalement différentes.

Ce que fait la v2

Genetic Programming

Les protocoles sont des arbres : SCRAMBLE, INTERLEAVE, REPEAT, CHECKSUM, REVERSE, XOR… Mutation et crossover de sous-arbres.

Multi-objectif + Niches

Fitness vectorielle (delivery, integrity, efficiency, resilience). Tri Pareto + crowding + speciation.

Lancer l’évolution (la vraie affaire)

Le moteur est un script Python. Télécharge le code, puis :

pip install numpy

# Évolution standard
python hostile_protocol_evolution.py --generations 20 --pop 36 --hostile medium

# Environnement extrême
python hostile_protocol_evolution.py --generations 25 --pop 40 --hostile extreme

Voir / cloner le dépôt GitHub

Exemple d’arbre émergent

REPEAT(2.0)
  SCRAMBLE(3142.0)
    ADD_PARITY()
      REVERSE()

La structure exacte change à chaque run. C’est le point.

Imagine a little package 📦

📦 The package

It's a message we want to send.

🛤️ The path

It's the network. Sometimes the path damages or loses the package.

🛡️ The arena

It tries different ways to protect the message on its journey.

🏁 At the end

The package can arrive intact, arrive damaged, or get lost along the way.

This all happens in a computer simulation. The package and the path are pictures that help explain messages and the network.

What's inside the boxes?

A box carries a message. Choose a short sentence, a color, a small code, or a mix. See what was sent and what can be read at the end.

💬 A sentence

For example: “I ate an apple today.”

🎨 A color

A color name travels as a message.

🔢 A code

A short sequence of characters goes inside the box.

📬 At the end

The contents can be intact, changed, unreadable, or lost. Only the actual trial result is shown.

The settings, in simple words

📦 Population

The number of box designs (protocols) tested each round. One design can send several messages.

🌱 Generations

The number of rounds. Selected designs can give rise to new designs in the next round.

🎲 Seed

A number for repeating the same random draws. Use the same number and settings to repeat the same experiment.

📊 The graph

It helps follow recorded trial results across rounds. A delivered box may contain a damaged message.

Small boxes and offspring are visual metaphors for evolution: the model does not actually nest boxes.

An arena for exploring evolution

Set your population and environment, then follow generations in a French or English application. The characters represent network mechanisms; animations show a sample of transmissions actually recorded by the engine.

Observe

Start, pause, or advance one generation at a time. Colors show whether a message is intact, corrupted, or lost.

Understand

Explore measurements, the log, and a protocol's clickable tree. Before-and-after examples come from recorded traces.

Keep your work

Export an experiment as JSON or CSV and reopen a JSON replay.

Keep the context

Results describe a simulation, not a physical network. Delivery does not guarantee intact content.

Explore v2 and the project's history
We no longer design. We let things evolve.
What survives no longer needs to resemble TCP, files, or pages.

Populations of protocols (represented as operation trees) compete under bit noise, packet loss, variable latency, failures and adversarial attacks. Natural selection decides. The goal is to discover radically different abstractions.

What v2 does

Genetic Programming

Protocols are trees: SCRAMBLE, INTERLEAVE, REPEAT, CHECKSUM, REVERSE, XOR… Mutation changes parts of a tree; crossover exchanges subtrees.

Multi-objective + Niches

Vector fitness (delivery, integrity, efficiency, resilience). Pareto sorting, crowding and speciation.

Run the evolution

The engine is a Python script. Download the code, then run:

pip install numpy

# Standard evolution
python hostile_protocol_evolution.py --generations 20 --pop 36 --hostile medium

# Extreme environment
python hostile_protocol_evolution.py --generations 25 --pop 40 --hostile extreme
