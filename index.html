Imagine a little package 📦

📦 The package

It's a message we want to send.

🛤️ The path

It's the network. Sometimes the path damages or loses the package.

🛡️ The arena

It tries different ways to protect the message on its journey.

🏁 At the end

The package can arrive intact, arrive damaged, or get lost along the way.

This all happens in a computer simulation. The package and the path are pictures that help explain messages and the network.

What's inside the boxes?

A box carries a message. Choose a short sentence, a color, a small code, or a mix. See what was sent and what can be read at the end.

💬 A sentence

For example: “I ate a red apple.”

🎨 A color

A color travels as a hexadecimal message such as #FF6B8B.

🔢 A code

A short sequence of characters goes inside the box.

📬 At the end

The contents can be intact, changed, unreadable, or lost. Only the actual trial result is shown.

The settings, in simple words

📦 Population

The number of box designs (protocols) tested each round. One design can send several messages.

🌱 Generations

The number of rounds. Selected designs can give rise to new designs in the next round.

🎲 Seed

A number for repeating the same random draws. Use the same number and settings to repeat the same experiment.

📊 The graph

It helps follow recorded trial results across rounds. A delivered box may contain a damaged message.

Small boxes and offspring are visual metaphors for evolution: the model does not actually nest boxes.

An arena for exploring evolution

Set your population and environment, then follow generations in the local Windows application. The characters represent network mechanisms; animations show a sample of transmissions actually recorded by the engine.

Observe

Start, pause, or advance one generation at a time. Colors show whether a message is intact, corrupted, or lost.

Understand

Explore measurements, the log, and a protocol's clickable tree. Before-and-after examples come from recorded traces.

Review the packages

Open the history to review messages after the test. It stays available while the app is open and clears with Restart. You can also export a JSON file to keep it.

Keep the context

Results describe a simulation, not a physical network. Delivery does not guarantee intact content.

Get started on Windows 10 or 11

The arena is a local Python application. This page introduces the project; it does not run the simulation in your browser.

v4 package for 64-bit Windows 10/11: download the ZIP, extract it completely, open the RawHostileSelect folder, then double-click START THE APP.bat.

Install from source code

  1. On GitHub, download the code with Code → Download ZIP and extract the folder.
  2. Install Python 3 with Tcl/Tk and pip if needed. Open a terminal in the extracted folder and run:
py -3 -m pip install -r requirements.txt --target .deps
  1. Double-click START_RawHostileSelect.bat.

The source-code download and Windows package are separate. The full guide explains installation, measurements, and the prototype's limitations.

Explore v2 and the project's history
We no longer design. We let things evolve.
What survives no longer needs to resemble TCP, files, or pages.

Populations of protocols (represented as operation trees) compete under bit noise, packet loss, variable latency, failures and adversarial attacks. Natural selection decides. The goal is to discover radically different abstractions.

What v2 does

Genetic Programming

Protocols are trees: SCRAMBLE, INTERLEAVE, REPEAT, CHECKSUM, REVERSE, XOR… Mutation changes parts of a tree; crossover exchanges subtrees.

Multi-objective + Niches

Vector fitness (delivery, integrity, efficiency, resilience). Pareto sorting, crowding and speciation.

Run the evolution

The engine is a Python script. Download the code, then run:

pip install numpy

# Standard evolution
python hostile_protocol_evolution.py --generations 20 --pop 36 --hostile medium

# Extreme environment
python hostile_protocol_evolution.py --generations 25 --pop 40 --hostile extreme
